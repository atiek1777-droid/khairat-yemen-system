# معامل خيرات اليمن — نظام إدارة التوزيع والمبيعات

نظام ويب كامل لإدارة توزيع الزيت والمخزون والمبيعات والعملاء والديون والمصروفات والتسويات الأسبوعية والتقارير، مبني بـ Next.js وSupabase، بواجهة عربية بالكامل واتجاه RTL.

## التقنيات المستخدمة
- **Next.js 14** (App Router) + **TypeScript**
- **Tailwind CSS** بنظام تصميم مخصص (ألوان وهوية معامل خيرات اليمن)
- **Supabase**: قاعدة بيانات PostgreSQL + المصادقة (Auth) + Row Level Security
- **React Hook Form + Zod** للتحقق من صحة النماذج
- **Recharts** للرسوم البيانية في لوحة التحكم
- **jsPDF + html2canvas** لتصدير PDF بدعم كامل للعربية
- **SheetJS (xlsx)** لتصدير Excel
- خط **Tajawal** مُستضاف محلياً (لا يعتمد على اتصال بجوجل عند البناء)

## الإعداد المحلي

### المتطلبات
- Node.js 18.18 أو أحدث
- حساب Supabase مجاني (https://supabase.com)

### الخطوات
```bash
npm install
cp .env.example .env.local
# ضع القيم الحقيقية داخل .env.local (انظر قسم إعداد Supabase أدناه)
npm run dev
```
افتح http://localhost:3000

## إعداد Supabase

1. أنشئ مشروعاً جديداً على https://supabase.com
2. اذهب إلى **SQL Editor** ونفّذ الملفات التالية **بالترتيب**:
   1. `supabase/schema.sql`
   2. `supabase/policies.sql`
   3. `supabase/seed.sql` (اختياري — بيانات تجريبية، انظر الخطوة التالية أولاً)
3. من **Settings → API** انسخ:
   - `Project URL` → ضعه في `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` → ضعه في `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role key` (سرّي جداً) → ضعه في `SUPABASE_SERVICE_ROLE_KEY` (مطلوب فقط لإدارة المستخدمين من صفحة "المستخدمون")
4. من **Authentication → Providers → Email**: تأكد أن **"Confirm email" مُعطّل (Disabled)**. النظام يستخدم بريداً إلكترونياً صناعياً داخلياً خلف اسم المستخدم، ولا يُرسل له أي رسائل تأكيد.

## إنشاء أول مستخدم مدير

النظام يحتاج أول حساب مدير قبل تشغيله، وأسهل طريقة:

1. في **Authentication → Users** داخل لوحة Supabase، اضغط **Add user**:
   - Email: `admin@khairatyemen.local`
   - Password: اختر كلمة مرور قوية
   - فعّل **Auto Confirm User**
2. انسخ الـ **User UID** الذي تم إنشاؤه
3. افتح `supabase/seed.sql`، استبدل كل حالات
   `00000000-0000-0000-0000-000000000000` بالـ UID الحقيقي، ثم نفّذ الملف من SQL Editor
   (هذا سينشئ سجل المصنع والمنتج والموزّع التجريبي وبيانات 02-09-2026)
4. سجّل الدخول بالتطبيق باسم المستخدم `admin` وكلمة المرور التي اخترتها

> بعد إنشاء المدير، يمكنك إنشاء بقية المستخدمين (موزّعين ومالك مصنع) مباشرة من صفحة **المستخدمون** داخل التطبيق — لا حاجة للرجوع إلى Supabase مرة أخرى.

## النشر على Vercel

1. ارفع المشروع إلى مستودع GitHub (انظر القسم التالي)
2. من https://vercel.com اضغط **Add New → Project** واختر المستودع
3. **Framework Preset**: يكتشفه Vercel تلقائياً كـ Next.js — لا حاجة لتغيير شيء
4. **Build Command**: `next build` (افتراضي)
5. **Output**: تلقائي (`.next`) — لا تغيّره
6. أضف متغيرات البيئة الثلاثة في **Environment Variables** (نفس أسماء `.env.example`)
7. اضغط **Deploy**

راجع بطاقة النشر الفنية في نهاية هذا الملف لتفاصيل دقيقة إضافية.

## الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| **مدير النظام** | كل شيء: المستخدمون، الموزّعون، الإعدادات، كل العمليات، الحذف، سجل العمليات |
| **مالك المصنع** | عرض فقط لكل البيانات والتقارير، ما لم يمنحه المدير صلاحية "التعديل" |
| **موزّع** | يرى ويُدخل بيانات نطاقه فقط (مبيعاته، عملاؤه، عهدته، مصروفاته)، ولا يحذف سجلات مالية إلا بإذن خاص |

الحماية مطبّقة على مستوى قاعدة البيانات عبر **Row Level Security**، وليس فقط بإخفاء الأزرار في الواجهة.
